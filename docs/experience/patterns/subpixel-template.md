# 慢移时区分弱匹配和模板漂移

**信号：** 目标仍然可见，小幅移动后圆环突然消失；或者圆环持续显示，却慢慢偏离点击的笔画。后者不能只看匹配帧数，要独立测量圆心相对实物的位置。

| 受控复现 | 机制与处理 |
| --- | --- |
| 对确定性纹理做双线性重采样，沿两轴各走半个分析像素。旧版本第一次位移就报 `WEAK_MATCH`。 | 模板按两像素步长取样，高频纹理对采样位置敏感。先在搜索小窗内做可分离的五点低通，再以相同方式提取模板和候选；匹配和唯一性门槛不变。滤波需要在裁切区域内多留两个像素。 |
| 初版低通修正后，图案沿一轴每帧走 ⅛ 像素；到第 9 帧，标记横坐标仍是 42.5，而真值已是 43.625。 | 每次强匹配都用整数中心的新外观更新模板，会把位移当作外观变化。几乎相同的样本无需学习；只有外观变化、位置唯一且局部相关峰接近整数中心时，才更新模板。仅检查相关峰是否居中仍未通过此序列。 |

**验证：** [PatchTrackerTest](../../../app/src/test/java/com/lumi/camera/camera/PatchTrackerTest.kt) 中的半像素往返、⅛ 像素慢移、渐转、重复候选和遮挡用例均通过。已在确定性序列验证；不能据此认定此前 PKX110 的所有丢点均由上述机制造成。低通也会削弱特别细的纹理；当图案本身不足以区分时应隐藏标记，不能调低置信门槛来强行显示。
