# Lumi 企业级上线进化战略（从技术原型到可发布商业相机 App）

**日期：** 2026-11-27　｜　**前置文档：** [Lumi 下一步产品与技术战略](../11.26/2026-11-26_Lumi下一步产品与技术战略.md)、[Lumi 影像质感与特写找光升级方案](./2026-11-27_Lumi影像质感与特写找光升级方案.md)　｜　**目标阶段：** P1（主力相机及格线）→ P2（影像与 AI 壁垒）→ P3（企业级上线底座）

## 1. 现状诊断：为什么当前版本仍像“高完成度原型”而非可上线产品

经过 S1–S8 的快速迭代，Lumi 已跑通「端侧候选框 + 云端 VLM 摄影导演 + 端侧 60fps 绿环引导 + 实时 GL 滤镜 + 参考图打卡 + 拍后轻复盘」的核心闭环。但站在**真实面向大众上线的商业级相机 App**标准审视，当前代码库在以下 **5 个维度** 存在明显硬伤：

| 维度 | 当前现状与代码层根因 | 对真实用户的直接影响 |
| --- | --- | --- |
| **1. 相机基本功（Table Stakes）** | `MainActivity.kt` 点击取景器直接发起 `AI 构图`，抢占了“点按对焦/滑条调曝光”；`AndroidManifest.xml` 锁死竖屏；缺少闪光灯、画幅切换、倒计时、音量键快门、多张相册流（重开 App 后左下角即清空） | 用户无法把 Lumi 当作主力相机替代系统相机，试玩两张就会切回原生相机 |
| **2. AI 构图与导演深度** | 高度依赖单次云端往返（1.5–4s），无离线端侧构图基线；云端输出仅收敛在 7 个固定几何槽位；人像导演仅有 12 字静态短句，缺少姿态引导线与连续拍摄反馈 | 电梯/景区/弱网直接失效；构图建议在多场景下“像升级版九宫格”，缺少真正的专业摄影师降维打击感 |
| **3. 影像质感与出图性能** | `FilterShader.kt` 仅靠全局数学调色参数，缺少 3D LUT、Filmic 高光滚降与精细肤色保护；`PhotoFilterRenderer.kt` 拍照时全尺寸 CPU 解码 → GL 渲染 → 软件重编码，内存峰值高且无后台异步出图队列；滤镜选择器缺少实时缩略图 | 人像开胶片/暖调滤镜易偏黄发灰；连续拍照卡顿阻塞；选滤镜靠盲猜名字 |
| **4. 物理手感与微交互（Craft）** | 缺少快门瞬闪、成片飞入相册、平滑变焦阻尼、分级触觉震动与快门反馈音 | 静态 UI 干净，但用起来像工具 Demo，缺乏“大厂旗舰相机”的精密机械手感 |
| **5. 企业级工程与上线底座** | 客户端直连 OpenAI 协议并要求手填 `Base URL / Model / API Key`；`MainActivity.kt`（1850+ 行）与 `CameraSession.kt`（1800+ 行）已成为巨型上帝类；`app/build.gradle.kts` 尚未配置 Release 混淆/签名、无 Crash/ANR 监控、无核心业务埋点与多厂商 Android 兼容矩阵 | 无法直接面向 C 端分发与商业化变现，版本迭代易互相踩坏，线上故障不可见、不可控 |

## 2. 进化总路线图（三阶段演进）

坚持**「先过主力相机及格线 → 再立专业影像与 AI 壁垒 → 同步夯实企业级发布底座」**原则，分三阶段推进：

- **P1：主力相机基本功与交互手感（让用户愿意日常打开）**
- **P2：专业影像质感与端云双层 AI 导演（让用户真正拍出超越系统相机的成片）**
- **P3：商业化后端网关、架构解耦与上线发布体系（让产品稳定、安全、可扩展、可运营）**

---

## 3. P1 阶段：补齐主力相机基本功与物理手感

**阶段目标：** 解决“不像一台成熟相机”的体验短板，做到零学习成本、顺手、跟手、可连续拍一卷照片。

### 3.1 解耦核心拍摄手势（对焦/测光 vs AI 选主体）
- **单击取景器**：回归相机直觉——**对焦 + 点测光**，显示暖金细线对焦方框，右侧附带小太阳垂直滑条实时微调 EV 曝光补偿（2.5 秒无操作淡出）。
- **长按取景器 350ms** 或 **点击右下角 `AI 构图`**：明确触发 AI 主体锁定与构图引导（长按可指定任意想要的主体并锁死 `AE/AF` 开关选项）。
- **双指捏合 / 底部倍率条滑动**：统一经过阻尼平滑插值曲线，消除硬切倍率时的画面跳变感。

### 3.2 补齐相机标配硬能力
1. **重力感应旋转适配（不重建相机流）**：保持竖屏 Activity 锁定以防止旋转重建导致取景中断，通过 `OrientationEventListener` 实时将按钮图标、文字胶囊、水平仪与成片 EXIF 方向平滑旋转至 `0° / 90° / 270°`，横屏拍风景/合影自然顺手。
2. **基础拍摄工具栏（收纳于简洁二级条，不污染取景器）**：
   - 闪光灯四态：`自动 / 开启 / 关闭 / 常亮补光（Torch）`；
   - 画幅切换：`3:4（默认） / 1:1 / 9:16（全屏）`，同步联动取景器遮罩、构图坐标与出图裁剪；
   - 倒计时自拍：`关闭 / 3s / 10s`（配合屏幕大字倒数 + 轻触觉脉冲）；
   - 实体音量键快门（`KeyEvent.KEYCODE_VOLUME_UP/DOWN` 拦截拍照）。
3. **内置轻量相册流（替代“单张临时复盘”）**：
   - 启动时通过 `MediaStore` 查询 `Pictures/Lumi` 最新照片自动填充左下角缩略图，不再重开即空；
   - 点击左下角进入全屏暗黑相册查看器：支持左右滑动浏览整卷照片、双指缩放看细节、一键对比原图与精裁方案、收藏/删除/系统分享、查看拍摄参数（焦段/快门/ISO/滤镜名）。

### 3.3 后台异步出图队列与旗舰级快门手感
- **异步出图管线（`CapturePipeline`）**：快门按下瞬间立即完成拍照回调并释放快门按钮可继续连拍；滤镜渲染、EXIF 写入与 MediaStore 落盘进入有界单线程/双线程后台队列（防止 OOM），左下角缩略图带微妙环形进度提示，完成后平滑刷新。
- **物理微交互（Craft）**：
  - 按快门触发 `70ms` 柔和黑闪 + 按钮按压缩放弹性反馈；
  - 水平仪归零（`±0.8°`）、光学焦段磁吸刻度、绿环对齐就绪分别绑定差异化轻震动反馈（`CLOCK_TICK` / `CONFIRM`）。

## 4. P2 阶段：建立专业影像质感与端云双层 AI 壁垒

**阶段目标：** 做出“系统相机给不了、普通滤镜 App 做不到”的真出片能力，让 AI 构图与滤镜质感成为核心留存与付费理由。

### 4.1 影像色彩科学升级（3D LUT + 人像肤色保护 + 实时缩略图）
- **升级 OpenGL 着色管线为 3D LUT + 参数微调混合架构**：
  - 9 款风格基底由专业调色师/离线校准生成的 `33×33×33` 3D LUT（`.cube` / PNG strip）驱动，确保高光 Filmic 柔和滚降、阴影色彩分离、胶片密度层次达到商业级审美品味；
  - AI 实时动态微调仍通过轻量 Uniform 叠加在 3D LUT 之后，实现“专业电影基底 + 现场环境自适应”。
- **独立人像肤色保护通道**：在 GLSL 中基于 YCbCr / HSV 肤色椭圆区间加权保护，保证开启冷调/胶片/复古 CCD 滤镜时，人脸不发青、不发黄、不发灰。
- **滤镜实时预览条**：基于当前低分辨率取景帧纹理，在滤镜抽屉中实时渲染每款风格的缩略效果图，告别“盲选滤镜名”。
- **低内存出图优化**：探索 `HardwareBuffer` / 分块渲染（Tiled GL Rendering）或降采样复用 EGL Context，将高像素滤镜成片耗时压至 `< 400ms`，峰值内存降低 50% 以上。

### 4.2 端云双层 AI 构图（离线秒级可用 + 云端专业导演）
彻底打破“没网不能用、每次等 3 秒”的玩具感：

1. **端侧离线基线层（`< 30ms`，零网络依赖）**：
   - 在网络断开或云端请求等待期间，端侧基于 **ML Kit 人脸/主体 + 显著性重心 + 水平线/竖直线检测**，毫秒级给出基础构图引导（三分留白、人像留头距、建筑横平竖直、防裁切提示）；
   - 网络正常时，端侧先出“瞬时初判”，云端返回后再平滑升级为深度导演方案，消除 2–3 秒的干等空白期。
2. **云端摄影导演能力升维（突破 7 个固定槽位）**：
   - **多维构图语义**：扩展支持**前景借景、引导线汇聚、建筑仰拍透视校正、多人合影重心平衡、人景占比（如“人占画面 1/4 突出山海”）**；
   - **人像姿态线框示范（Pose Silhouette）**：结合参考图或人像场景，在取景器叠加低透明度可开关的人像轮廓示范线（头肩朝向/站位比例），配合大白话口令（“模特右脚往前迈半步、侧身看窗外”），解决“不会摆拍”痛点；
   - **连续拍摄迭代点评（Session Memory）**：同一场景连拍第 2 张时，云端感知上一张的构图/表情/光影短板，给出“比上一张更好”的增量微调建议，形成真正的跟拍摄影师体验。

## 5. P3 阶段：企业级工程底座、商业网关与上线发布体系

**阶段目标：** 把个人开发的代码库重构为多人可协作、线上可观测、安全可商业化、多机型稳定运行的企业级工程。

### 5.1 架构解耦与状态机治理（消灭上帝类）
将当前过度膨胀的 `MainActivity.kt` 与 `CameraSession.kt` 拆分为清晰的 **单向数据流（MVI / MVVM）+ 模块化分层**：

```text
app/
 ├── ui/                  # 纯 Compose 声明式视图（拆分 TopBar / Viewfinder / Overlays / ControlDeck / Gallery / Settings）
 ├── viewmodel/           # CameraViewModel + 不可变 CameraUiState + 明确 CameraIntent 事件流
 ├── domain/
 │    ├── guidance/       # 构图状态机（Idle -> Analyzing -> Tracking -> Ready -> Lost）与 3D 投影求解
 │    ├── director/       # 端云融合决策器（端侧基线 + 云端策略合并 + 超时降级）
 │    └── capture/        # 异步拍照与出图队列管理器
 ├── data/
 │    ├── camera/         # CameraX + Camera2 硬件抽象层（含厂商兼容策略表）
 │    ├── filter/         # OpenGL 3D LUT 引擎与纹理缓存池
 │    ├── gallery/        # MediaStore 相册仓库
 │    └── network/        # 统一 AI 网关客户端（支持超时取消、指数退避、模型降级）
 └── observability/       # 埋点事件、性能打点、Crash 脱敏上报
```

### 5.2 自有服务端 AI 网关（BFF）与安全商业化
- **彻底移除普通用户手动配置 `API Key / Base URL` 的入口**（仅保留 Debug 内部调试开关）。
- **建设轻量 BFF 网关（如 Cloud Run / Edge Worker / FastAPI / Go）**：
  - **统一鉴权与防刷**：设备匿名令牌 + 账号体系，签发短期 Token，API Key 严格保存在服务端；
  - **多模型路由与容灾**：主模型超时或限流时自动无缝切换备用视觉模型，保障端到端可用率 `>= 99.5%`；
  - **Prompt 与策略热更新**：构图提示词、滤镜推荐映射、场景模板由服务端版本化下发，无需发版即可持续调优出片效果；
  - **分级商业化与配额**：端侧离线基础拍摄/基础滤镜永久免费，云端深度导演 / 参考图打卡 / 高阶大师 LUT 按次或订阅计费。

### 5.3 发布工程、多机型兼容矩阵与可观测性
1. **Release 构建与安全加固**：
   - `app/build.gradle.kts` 补齐 `release` buildType、R8 代码混淆与资源压缩（`isMinifyEnabled = true`、`isShrinkResources = true`）、正式签名配置（Keystore 走 CI 环境变量不入库）及 ProGuard 规则验证（ML Kit / MediaPipe / CameraX 反射保活）。
2. **线上监控与核心指标看板**：
   - 接入 Crash / ANR 监控（Firebase Crashlytics 或 Sentry），配置符号表（mapping.txt）自动上传；
   - 建立 **北极星指标体系**，用数据驱动迭代而非凭感觉改功能：
     - **性能健康**：冷启动到首帧出图 `< 800ms`；快门延迟 `< 250ms`；滤镜异步落盘 `< 450ms`；Crash-free 用户率 `>= 99.7%`；
     - **AI 体验**：AI 构图端到端 P50 `< 1.2s`、P95 `< 2.5s`；请求成功率 `>= 98%`；
     - **产品价值**：AI 推荐触发后的**绿环对齐率**、**对齐后实际快门转化率**、**成片留存/分享率**、**7 日复拍留存率**。
3. **Android 多厂商真机兼容矩阵**：
   - 建立 `DeviceQuirks` 配置表，针对主流品牌（OPPO/OnePlus、小米、vivo、三星、华为/荣耀、Pixel）分别验证并兜底：CameraX Extensions 支持度、广角/长焦物理切换跳变、前置镜像 EXIF、GL `SurfaceTexture` 色彩空间（BT.601/BT.709/P3）与暗光 AE 锁定行为。
4. **合规与隐私就绪（上架应用商店硬门槛）**：
   - 最小化权限申请与清晰引导页（相机、相册仅按需请求，明确告知“画面仅用于实时构图分析，不留存隐私原图”）；
   - 补齐隐私政策、用户协议、AI 生成/辅助内容合规标识与注销删除链路。

## 6. 建议的近期执行优先级（从下个迭代开始）

为避免“大重构停滞不前”，建议采用**「小步快跑、每两周出一个可真机日常使用的里程碑」**节奏：

| 迭代 | 重点交付 | 验收标准（DoD） |
| --- | --- | --- |
| **Milestone 1（P1 核心）** | 手势解耦（单击对焦+EV滑条 vs 长按/按钮 `AI 构图`）+ 重力感应旋转 + 闪光灯/画幅/倒计时/音量键快门 | 连续外出日常拍 50 张不切回系统相机，横竖屏与弱光对焦体验顺滑 |
| **Milestone 2（P1 闭环）** | 后台异步出图队列 + 内置 `Pictures/Lumi` 全屏相册流 + 快门微动效与分级触觉反馈 | 滤镜模式支持连续快门不阻塞、无 OOM；杀进程重开左下角仍展示最新成片并可左右滑看整卷 |
| **Milestone 3（P2 质感）** | 3D LUT 引擎 + 独立肤色保护 + 滤镜实时缩略图预览 | 实拍人像在 9 款滤镜下肤色自然通透，选滤镜所见即所得 |
| **Milestone 4（P2 AI 升维）** | 端侧离线 `< 30ms` 构图基线 + 建筑透视/多人场景扩展 + 人像姿态示范线框 | 飞行模式/弱网下 `AI 构图` 仍可秒级给出准确构图与水平引导；有网时无缝升级为云端深度导演 |
| **Milestone 5（P3 上线底座）** | `MainActivity`/`CameraSession` MVVM 拆分 + 服务端 AI 代理网关（免配 Key）+ Release 混淆签名 + Crash/埋点接入 | 无本地 API Key、完整 Release APK 可直接提交内测分发（Firebase App Distribution / 蒲公英 / 应用商店） |
